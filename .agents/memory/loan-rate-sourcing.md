LoanCompare India should check official bank pages daily for current loan-rate information.

**Why:** the user selected official pages with daily checks as the source strategy.

**How to apply:** Store source URLs and verification timestamps. Update only values explicitly published by the bank. Mark unavailable or unparseable sources as unverified/manual review; never present seed rates as live or infer missing values.
